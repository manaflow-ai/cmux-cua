`cmux-cua permissions` is a macOS-only command. It is not part of the auto-generated [CLI reference](/reference/cmux-cua/cli-reference) because it has no Windows or Linux counterpart, so it is documented here.

## `cmux-cua permissions` (macOS)

Inspect or request the macOS TCC grants the driver needs (Accessibility and Screen Recording). Embedded-mode hosts do not use `cmux-cua permissions grant`; the host app requests these grants itself, as described in [Embedding](/reference/cmux-cua/embedding).

```bash
cmux-cua permissions status   # report grant status; read-only, no prompt
cmux-cua permissions grant    # launch CmuxCua via LaunchServices so the prompt attributes to the app
```

**Flags:**

| Flag | Description |
| ---- | ----------- |
| `--json` | Machine-readable status output. |

`cmux-cua mcp` runs cmux CUA as a stdio MCP server. Register it when you want an MCP-capable agent to drive the **host desktop**: installed apps, signed-in browser sessions, local files opened in apps, and the current OS user session.

<Callout type="info">
  This connects an agent to cmux CUA on the current machine. To create disposable cloud desktops, use [Cua Sandbox](/tutorials/your-first-cloud-sandbox) instead.
</Callout>

## Before you start

Install cmux CUA and verify it can see the host desktop:

```bash
cmux-cua --version
cmux-cua call list_apps
```

On macOS, grant Accessibility and Screen Recording before connecting an agent:

```bash
cmux-cua permissions status
```

See [Install cmux CUA](/how-to-guides/driver/install) and [macOS permissions](/reference/cmux-cua/macos-permissions) for setup details.

## Generate the client config

Use `mcp-config` to print the registration command or JSON for a supported client:

```bash
cmux-cua mcp-config --client <client>
```

The generated reference is the source of truth for the complete roster and exact command shapes: [`cmux-cua mcp-config`](/reference/cmux-cua/cli-reference#cmux-cua-mcp-config).

## Claude Code

Register the plain stdio server:

```bash
claude mcp add --transport stdio cmux-cua -- cmux-cua mcp
claude mcp list
```

Claude Code can also use cmux CUA's computer-use compatibility profile. Generate the current command:

```bash
cmux-cua mcp-config --client claude
```

That profile exposes the same driver tools under the compatibility server name. It still runs cmux CUA over MCP; Anthropic's native computer-use API is separate.

## Codex

Print the app-oriented Codex Computer Use command:

```bash
cmux-cua mcp-config --client codex-computer-use
```

It registers the exact ten-tool app contract and uses the Sky cursor:

```bash
codex mcp add cua-computer-use -- /Users/you/.local/bin/cmux-cua mcp --codex-computer-use-compat
codex mcp list
```

Restart Codex or open a fresh session after adding the server. Call
`get_app_state` before the first action in each turn; every successful action
returns the refreshed state and JPEG.

To expose cmux CUA's broader pid/window-native catalog instead, print the
existing native Codex command:

```bash
cmux-cua mcp-config --client codex
```

It emits a registration using the absolute installed binary path, which avoids `PATH` issues in app-launched Codex sessions:

```bash
codex mcp add cmux-cua -- /Users/you/.local/bin/cmux-cua mcp
codex mcp list
```

Install the cmux CUA skill for the app interaction loop and action-time confirmation policy:

```bash
cmux-cua skills install
cmux-cua skills status
```

## Cursor

Generate the Cursor snippet:

```bash
cmux-cua mcp-config --client cursor
```

Paste the JSON into `~/.cursor/mcp.json`, or `.cursor/mcp.json` for project scope:

```json
{
  "mcpServers": {
    "cmux-cua": {
      "command": "cmux-cua",
      "args": ["mcp"],
      "type": "stdio"
    }
  }
}
```

Restart Cursor and confirm `cmux-cua` appears in the MCP server list.

## Other supported clients

`mcp-config` also prints the right shape for clients that use a config file or a different add command.

| Client | Generate with | Notes |
|---|---|---|
| Antigravity | `cmux-cua mcp-config --client antigravity` | Paste into `~/.gemini/config/mcp_config.json`; `--client gemini` is a legacy alias. |
| OpenClaw | `cmux-cua mcp-config --client openclaw` | Normal gateway-spawned MCP does not inherit OpenClaw.app's macOS permission grants; embedded hosts should use [Embedding](/reference/cmux-cua/embedding). |
| OpenCode | `cmux-cua mcp-config --client opencode` | Configure a real MCP server so screenshots are preserved in image blocks. |
| Hermes | `cmux-cua mcp-config --client hermes` | Paste under `mcp_servers` and reload MCP servers in Hermes. |
| Pi | `cmux-cua mcp-config --client pi` | Pi does not support MCP natively; use one-shot `cmux-cua call …` commands from its shell. |
| Qwen Code | `cmux-cua mcp-config --client qwen` | Supports both a CLI add command and `~/.qwen/settings.json`. |
| Factory Droid | `cmux-cua mcp-config --client droid` | Supports CLI and JSON config forms. |
| ZCode | `cmux-cua mcp-config --client zcode` | Configure MCP in the GUI, or use `zai mcp add` for Z.ai's separate CLI. |

## Generic MCP JSON

For any client that accepts the standard `mcpServers` shape, print the generic config:

```bash
cmux-cua mcp-config
```

It returns:

```json
{
  "mcpServers": {
    "cmux-cua": {
      "command": "cmux-cua",
      "args": ["mcp"]
    }
  }
}
```

After saving the config, restart the client and confirm the `cmux-cua` server is connected.
